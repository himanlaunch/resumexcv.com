# ResumeX100 Job Saver

This Manifest V3 extension captures the visible job title, company, location, description, and source URL from common job boards and opens the ResumeX100 review queue.

## Load for testing

1. Open `chrome://extensions`.
2. Enable **Developer mode**.
3. Choose **Load unpacked** and select this folder.
4. Open a job posting and choose **Save and tailor** from the extension.

Before publishing, replace the production URL in `popup.js` if the app uses a different domain.
